# Movie_REC — CINEMATCH AI

A Netflix-inspired AI movie and TV series discovery platform powered by real-time similarity matching and 3D WebGL visuals.

## Highlights
- **Global Catalog (1,914 Titles):** Movies and TV series across 16+ languages (English, Telugu, Hindi, Tamil, Malayalam, Kannada, Spanish, Korean, Japanese, French, German, Italian, Turkish, Mandarin, Cantonese, Portuguese) parsed directly from CSV datasets.
- **AI Matchmaker:** Multi-factor similarity engine scoring genre affinity, critical acclaim, release era, language, and synopsis themes with 4 discovery modes (`Balanced`, `Genre Focus`, `Hidden Gems`, `Go Global`) and interactive Recharts analytics.
- **3D & Motion Experience:** Interactive 3D tilt poster cards with specular glare, Three.js WebGL hero lattice, Vanta.js atmospheric shader backdrop, and GSAP ScrollTrigger + Framer Motion animations.
- **Smart Explore Catalog:** Filter by format (`Movies` / `TV Series`), language, genre, country, rating, and release year with instant search and sorting.

## Tech Stack
React · Vite · Tailwind CSS · GSAP · Three.js · Vanta.js · Framer Motion · PapaParse · Recharts · Lucide Icons

## Run Locally
```bash
npm install
npm run dev
```
